# Редактор цін (для власника сайту)

Статичний GitHub Pages не має справжнього бекенду. Редактор цін захищений **легким паролем у браузері**.

## Змінити пароль

1. Відкрийте файл `editor-config.json` у репозиторії.
2. Змініть значення `"password"` (за замовчуванням стоїть плейсхолдер — **обов’язково змініть** перед використанням).
3. Зробіть commit і push на `main`.
4. Після rebuild GitHub Pages новий пароль почне діяти.

Пароль зберігається в репозиторії у відкритому вигляді; це лише щоб приховати кнопку від випадкових відвідувачів, а не криптографічний захист.

## Як користуватися

1. На сторінці «Продукція» натисніть «Увійти до редактора» і введіть пароль.
2. У цій вкладці браузера доступ зберігається до закриття вкладки (`sessionStorage`).
3. Відредагуйте ціни → «Завантажити products.json» → замініть файл у GitHub і зробіть push.
