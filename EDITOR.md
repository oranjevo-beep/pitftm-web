# Редактор цін (для власника сайту)

Статичний GitHub Pages не має справжнього бекенду. Редактор цін захищений **легким паролем у браузері** і **прихований від звичайних відвідувачів**.

## Змінити пароль

1. Відкрийте файл `editor-config.json` у репозиторії.
2. Змініть значення `"password"` (за замовчуванням стоїть плейсхолдер — **обов’язково змініть** перед використанням).
3. Зробіть commit і push на `main`.
4. Після rebuild GitHub Pages новий пароль почне діяти.

Пароль зберігається в репозиторії у відкритому вигляді; це лише щоб приховати інструмент від випадкових відвідувачів, а не криптографічний захист.

## Як відкрити редактор

На сторінці «Продукція» відвідувачі **не бачать** кнопок «Редагувати ціни» чи підказок про `products.json`.

Вхід для власника:

1. Натисніть дискретне посилання **«Увійти»** внизу сторінки продукції **або** відкрийте  
   `products.html?edit=1` / `products.html#edit`.
2. Введіть пароль. У цій вкладці доступ зберігається до закриття (`sessionStorage`).
3. З’являться кнопки редактора → змініть ціни → «Завантажити products.json» → замініть файл у GitHub і зробіть push.
